# TradeTalk

Drop site photos and get a daily-diary description for each one, ready to approve and paste into the Procore Daily Log.

- Live site: https://lesegomakgene-cell.github.io/tradetalk/
- Descriptions are written by Google Gemini using each person's own free API key (https://aistudio.google.com/apikey), stored only in their browser.
- Photos and approved descriptions are saved in the browser (IndexedDB) on that device. There is no server.

The whole app is `index.html`.
